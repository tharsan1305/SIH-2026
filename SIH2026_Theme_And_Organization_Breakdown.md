## 🎯 How to Use This Breakdown

### If you want to pick by **domain interest**:
- Passionate about **climate/weather/disaster response** → MoES (26 PS) is the richest single source
- Interested in **cybersecurity/national security** → NTRO (20 PS) + MHA (13 PS) = 33 PS combined
- Interested in **space/satellite tech** → ISRO (11 PS)
- Interested in **agriculture/rural India** → Rural Development + Fisheries/Animal Husbandry + Govt of Maharashtra agri PS

### If you want to pick by **flexibility** (propose your own idea):
- AICTE has **34 open slots** spread across themes — best option if you have an original idea that doesn't fit any fixed PS

### If you want **defense-tech prestige** (but expect difficulty):
- DRDO (9 PS) and MHA (13 PS) — most are 🔴 Difficult tier due to restricted data/domain expertise required (see [SIH2026_Difficulty_Levels.md](file:///d:/Sih/SIH2026_Difficulty_Levels.md))

### If you want **guaranteed public/open data** to build with:
- MoES (weather data via IMD), ISRO (Bhuvan/Bhoonidhi satellite data), Consumer Affairs (legal metrology — public standards documents)
